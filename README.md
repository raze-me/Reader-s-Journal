

# Reader's Journal

There are days when you take a book and read till 3am at night but after that day you never pick it up.
So here is Reader's Journal, just keep a record of it and note all completed chapters. So that when you are up another night again and dont know what to do so you can come and check here at Reader's Journal to complete those books.

A simple web app to save keep a record of your read books, either to flaut or just for you.
Like a books journal. Completely private.

- [Live Link](https://raze-me.github.io/Reader-s-Journal): Try it out NOW!

## Features

- **Add Books:** Record new book entries.
- **Delete Books:** Remove record of a stored book entry.
- **Reading Status:** Save books as fully or partially read.
- **Persistent Records:** Uses browser localStorage to retain records between page reloads.
- **Fun UI/Vibe:** Cool hc vibes.

## Installation

1. Clone the Repo:

```
git clone https://github.com/raze-me/Reader-s-Journal
```

2. Navigate to the directory:
```
cd readers-journal
```

3. Open the index.html in your browser.

## How to Use

1. Open the Reader's Journal
2. Click on Add button to add a book
3. Enter details of the book
4. Click on submit button to add it as an entry
5. To remove an entry, select the book and click on delete
